# 🛡️ Taller de Seguridad Digital: Concientización contra Phishing y Enlaces Falsos

Este proyecto corresponde a un taller práctico de **Responsabilidad Social Universitaria** enfocado en la prevención de ciberdelitos, suplantación de identidad y concientización sobre la importancia de verificar los enlaces externos antes de abrirlos.

---

## 🎯 Objetivo de la Dinámica del Taller

1. **La Simulación Inicial**: Se envía un correo electrónico de prueba a los participantes del taller con un asunto llamativo (ej. *"Actualización obligatoria de datos universitarios"* o *"Confirmación de asistencia"*).
2. **El Impacto Inicial**: Aquellos usuarios que abran el enlace sin verificar verán un mensaje directo e impactante:
   > *"¡Gracias por presionar el enlace! Pudimos descargar tus datos... ⚠️"*
3. **La Revelación Formativa**: Inmediatamente abajo, la página tranquiliza al usuario aclarando que es una **simulación educativa**, que **no se descargó ni capturó ningún dato personal**, pero explica cómo un ciberdelincuente real sí habría podido comprometer sus cuentas o dispositivo.
4. **Capacitación Interactiva**:
   - Explicación de los riesgos reales (phishing, robo de cookies, suplantación de identidad).
   - Las 4 reglas de oro para validar enlaces y remitentes.
   - **Simulador Interactivo de Casos en Vivo**: Un quiz donde los estudiantes practican detectando correos reales vs. trampas de phishing.
   - Registro de asistencia/aprendizaje del taller.

## 🚀 Despliegue en Vercel (100% Gratuito y en 2 Minutos)

Esta página está construida con **HTML5, CSS3 moderno y JavaScript Vanilla**, lo que permite desplegarla de inmediato en Vercel sin necesidad de configuraciones complejas de build.

### Opción 1: Conectar mediante GitHub (Recomendada)
1. Sube este repositorio a tu cuenta de GitHub (ver instrucciones abajo).
2. Ingresa a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
3. Haz clic en **"Add New..."** > **"Project"**.
4. Selecciona el repositorio de GitHub y presiona **"Deploy"**.
5. ¡Listo! Vercel te dará una URL pública tipo `https://tu-proyecto.vercel.app`.

### Opción 2: Usar Vercel CLI directamente desde la terminal
Si tienes Node.js instalado, puedes desplegar directamente:
```bash
npx vercel
```

## 🐙 Cómo subir este proyecto a GitHub

Ejecuta los siguientes comandos en la terminal dentro de esta carpeta:

```bash
# 1. Iniciar el repositorio local
git init

# 2. Agregar todos los archivos
git add .

# 3. Crear el primer commit
git commit -m "feat: Taller de concientizacion de seguridad digital y phishing"

# 4. Cambiar a rama principal
git branch -M main

# 5. Enlazar con tu repositorio de GitHub (reemplaza con tu URL de GitHub):
git remote add origin https://github.com/TU_USUARIO/NOMBRE_DEL_REPO.git

# 6. Subir el código
git push -u origin main
```
